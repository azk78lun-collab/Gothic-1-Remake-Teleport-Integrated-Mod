# G1R Community Service

Dependency-free Python service used by the optional community board and anonymous
installation counter.

It stores only:

- a random client UUID generated by the installer;
- the mod version and server-side timestamps;
- player-selected nicknames and public messages.

It does not accept or store Windows usernames, hardware identifiers, game paths,
save files, or raw client IP addresses. Player names are rendered with a
server-controlled `玩家·` prefix. Only authenticated administrator requests can
create messages rendered as `管理员`.

The systemd and Nginx templates in `deploy/` run the service as a restricted
account on `127.0.0.1:18182`. Set a random token of at least 32 characters in
`/etc/g1r-community.env`:

```ini
G1R_COMMUNITY_ADMIN_TOKEN=replace-with-a-long-random-token
G1R_COMMUNITY_DATABASE=/var/lib/g1r-community/community.sqlite3
```
